# Data Sources for Gene Expression Analysis

This folder contains links and instructions for downloading the datasets used in this project.  
Raw data is not included in the repository due to size limitations.

---

## 1. Tuberculosis Biomarker Dataset (GSE57736)
Used for generating the volcano plot (differentially expressed genes).

GEO Accession Page:  
https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE57736

Series Matrix File (processed expression values):  
https://ftp.ncbi.nlm.nih.gov/geo/series/GSE57nnn/GSE57736/matrix/

**Place the downloaded file here as:**  
`GSE57736_series_matrix.txt.gz`
